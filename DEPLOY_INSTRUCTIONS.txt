📤 PUSH TO GITHUB (DO THIS NOW!)
═══════════════════════════════════════════════════════════════

1. Go to GitHub.com → Create new repository
   Name: "ai-agent-builder" (or your choice)
   Keep it PUBLIC
   Don't initialize with README

2. Copy the commands GitHub shows, they'll look like:

   git remote add origin https://github.com/YOUR-USERNAME/ai-agent-builder.git
   git branch -M main
   git push -u origin main

3. Run those commands in your terminal in the project folder

═══════════════════════════════════════════════════════════════
🚂 DEPLOY BACKEND TO RAILWAY
═══════════════════════════════════════════════════════════════

1. Go to https://railway.app
2. Sign up with GitHub
3. New Project → Deploy from GitHub repo
4. Select your repository
5. Settings → Root Directory → "backend"
6. Variables → Add these:
   
   GROQ_API_KEY = your-groq-key-here
   CORS_ORIGINS = *

7. Settings → Networking → Generate Domain
8. SAVE YOUR BACKEND URL: https://______.railway.app
9. Test it: Open https://your-url.railway.app/api/
   Should see: {"message":"Forge agent builder API","status":"ok"}

═══════════════════════════════════════════════════════════════
▲ DEPLOY FRONTEND TO VERCEL
═══════════════════════════════════════════════════════════════

1. Go to https://vercel.com
2. Sign up with GitHub
3. Add New → Project → Import your repo
4. Root Directory → Edit → "frontend"
5. Environment Variables → Add:
   
   Name: REACT_APP_BACKEND_URL
   Value: https://your-railway-url.railway.app
   (NO TRAILING SLASH!)

6. Click Deploy
7. SAVE YOUR FRONTEND URL: https://______.vercel.app

═══════════════════════════════════════════════════════════════
🔗 CONNECT THEM (IMPORTANT!)
═══════════════════════════════════════════════════════════════

1. Go back to Railway
2. Variables → Edit CORS_ORIGINS
3. Change from "*" to your Vercel URL:
   https://your-project.vercel.app
   (NO TRAILING SLASH!)
4. Save → Railway will redeploy (wait 2 min)

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

CORS Error?
→ Railway → Variables → CORS_ORIGINS must exactly match Vercel URL
→ No trailing slash!
→ Use https:// not http://

Backend 500 Error?
→ Railway → View Logs → Check error
→ Usually: Wrong GROQ_API_KEY

Chat Not Streaming?
→ Backend must be on Railway (NOT Vercel)
→ Check browser console for errors
