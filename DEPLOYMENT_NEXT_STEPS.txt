TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: CORS error in browser console
Fix: Railway → Variables → CORS_ORIGINS must EXACTLY match Vercel URL
     No trailing slash, use https://

Problem: Backend returns 500 error
Fix: Railway → View Logs → Check error
     Usually: Wrong GROQ_API_KEY

Problem: Frontend won't build
Fix: Vercel → Settings → Root Directory must be "frontend"

Problem: Chat messages don't stream
Fix: Make sure backend is on Railway, not Vercel
     (Vercel serverless kills long connections)
