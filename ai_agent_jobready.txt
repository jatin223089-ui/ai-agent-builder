📋 PROJECT SUMMARY (60 SECONDS)
================================================================================

Forge is a NO-CODE AI platform that empowers users to create custom AI 
assistants in minutes without writing any code. It provides pre-built templates, 
an interactive quiz for personalized recommendations, and real-time chat with 
AI models (Llama, Mixtral) powered by the free Groq API.

Target Users: Students, writers, researchers, coders, strategists, and anyone 
who wants a personalized AI assistant.

🚀 HOW TO SETUP (5 MINUTES)
================================================================================

STEP 1: Get Free Groq API Key
  → Go to console.groq.com
  → Sign up (free)
  → Copy API key

STEP 2: Clone & Setup Backend
  → git clone https://github.com/jatin223089-ui/ai-agent-builder.git
  → cd backend
  → pip install -r requirements.txt
  → Create .env file:
     GROQ_API_KEY=your_key_here
     CORS_ORIGINS=http://localhost:3000
  → python -m uvicorn server:app --reload --port 8000

STEP 3: Setup Frontend (new terminal)
  → cd frontend
  → yarn install
  → Create .env file:
     REACT_APP_BACKEND_URL=http://localhost:8000
  → yarn start

STEP 4: Open Browser
  → http://localhost:3000
  → Take quiz or choose template
  → Create your first AI agent!

================================================================================
🐛 TROUBLESHOOTING GUIDE
================================================================================

CORS Error:
  → Ensure CORS_ORIGINS in backend matches frontend URL exactly
  → No trailing slashes: http://localhost:3000 (not localhost:3000/)

Database Issues:
  → Delete backend/forge.db to reset
  → Check file permissions
  → Verify database is created on first request

API Errors:
  → Verify Groq API key is correct in .env
  → Check daily rate limits (14,400 requests/day)
  → Ensure API key has correct permissions

Build Errors:
  → Clear node_modules: rm -rf node_modules && yarn install
  → Clear cache: yarn cache clean
  → Delete .craco.js if build issues persist

Connection Refused:
  → Ensure backend is running on port 8000
  → Ensure frontend is running on port 3000
  → Check no other processes using these ports
